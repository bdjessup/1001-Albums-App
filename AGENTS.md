# AGENTS.md

Liner is an Expo SDK 58 / React Native 0.88 app (iOS + Android) for 1001 Albums Generator. Single package at the repo root; routes live in `src/app`.

## Commands

- Package manager: `bun` (`bun.lock`). If `bun` isn't on `PATH`, it's usually `$HOME/.bun/bin/bun`.
- `bun run typecheck`, `bun run test` (vitest, `src/core/**/*.test.ts`) and `bun run lint` all run headless and are clean; keep them that way. `bun run check` runs all three.
- `bun run ios` / `bun run android` need simulators and are not runnable headless.
- Headless bundle check for both platforms: `EXPO_OFFLINE=1 bunx expo export --platform ios --platform android --output-dir /tmp/liner-export`.
- Headless config-plugin check: `EXPO_OFFLINE=1 bunx expo prebuild --no-install --clean`, then delete `ios/` and `android/` (both are gitignored).
- `bunx expo install` needs `EXPO_OFFLINE=1` in sandboxes that block api.expo.dev.
- Typed routes: `.expo/types/router.d.ts` is generated by `expo start`; without it, `Href` falls back to loose typing.

## Conventions

- `src/core` is pure TypeScript with no React Native imports, so it's unit tested in Node. Put API parsing, stats and formatting logic there, with tests.
- Platform differences go in `src/components/native/` as `name.ios.tsx` (iOS) + `name.tsx` (Android) with a shared `name.types.ts`. Screens import `./name` and never branch on platform for native controls.
- Prefer `@expo/ui` universal components (`@expo/ui`) when one tree can render natively on both platforms; drop to `@expo/ui/swift-ui` or `@expo/ui/jetpack-compose` in a platform file when it can't.
- Check platform with `process.env.EXPO_OS` (inlined by babel so the other platform's code is dropped) or `theme.isIOS`.
- Icons: add to `ICONS` in `src/components/icon.tsx` with both an SF Symbol and a Material Symbol name; both are type-checked.
- Colours and text come from the theme's semantic tokens (`useTheme()`, `<AppText variant>`), never hard-coded per screen.
- The 1001 Albums API allows ~3 requests/min. Never add polling; go through `albumsClient` (shared limiter) and TanStack Query.
